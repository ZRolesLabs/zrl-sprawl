The first public release of ZRL Sprawl, a screensaver for Windows 10 and 11: a real-time night flight over a neon city, across every monitor, with no network, no telemetry and no audio.

**Install:** download `ZRL-Sprawl.zip` below, right-click it and choose Properties, tick **Unblock**, press OK, extract it to a folder that can stay put, then right-click `ZRL-Sprawl.scr` and choose **Install**. Full steps, and what to do if Windows shows the "Windows protected your PC" box, are in the [README](https://github.com/ZRolesLabs/zrl-sprawl#install-it-about-2-minutes).

The zip is built from this repository's source by GitHub Actions and is not code-signed.
