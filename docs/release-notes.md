**1.0.1** steadies the billboards. The signs had a deliberate "glitch" effect (rows slipping sideways, and an occasional blink) that fired often enough to look like a broken picture. It is gone: every sign now holds still and reads cleanly. Distant signs no longer shimmer, and one sign that sat half hidden behind a tower has been moved into clear view.

**Install:** download `ZRL-Sprawl.zip` below, right-click it and choose Properties, tick **Unblock**, press OK, extract it to a folder that can stay put, then right-click `ZRL-Sprawl.scr` and choose **Install**. To update from 1.0.0, extract over the same folder. Full steps, and what to do if Windows shows the "Windows protected your PC" box, are in the [README](https://github.com/ZRolesLabs/zrl-sprawl#install-it-about-2-minutes).

The zip is built from this repository's source by GitHub Actions and is not code-signed.
