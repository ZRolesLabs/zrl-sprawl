ZRL SPRAWL @VERSION@ - a screensaver for Windows by ZRolesLabs
https://github.com/ZRolesLabs/zrl-sprawl

No network. No telemetry. No audio. No ads.

INSTALL
1. Keep this whole folder somewhere it can stay, for example
   C:\Users\<you>\ZRL-Sprawl. Do not run it from inside the zip.
2. Right-click ZRL-Sprawl.scr and choose Install.
   On Windows 11, choose "Show more options" first.
3. Screen Saver Settings opens with ZRL-Sprawl picked. Set the wait time
   and press OK.

To just watch it, double-click ZRL-Sprawl.scr.
Any key, click or mouse movement closes it.

IF WINDOWS SHOWS "Windows protected your PC"
The file is not code-signed, so SmartScreen does not know it.
Click "More info", then "Run anyway". To avoid the box altogether,
right-click the zip you downloaded, choose Properties, tick Unblock,
press OK, and extract it again.

REMOVE
Pick another screensaver (or None) in Screen Saver Settings, then delete
this folder. The view's cache is in
%LOCALAPPDATA%\ZRolesLabs\zrl-sprawl-wv2 and can be deleted too.

NEEDS
Windows 10 or 11, 64-bit, with the Microsoft Edge WebView2 Runtime
(already part of Windows 11 and of up-to-date Windows 10).

Options, source code and help: see the web page above.
